# How to run the project
Run the next commands:

1. Create an .venv

MacOS / Linux:
```
python3 -m venv venv
```

Windows:
```
python -m venv venv
```

2. Activate the venv
MacOS / Linux:
```
source venv/bin/activate
```

Windows:
```
.\venv\Scripts\Activate.ps1
```

3. Run the main file
```
python3 main.py
```

Windows:
```
python main.py
```
